
## About
This repository contains a collection of advanced embedded electronics projects,
including hardware designs, PCB layouts, firmware source code, and IoT integrations
for smart appliances and innovative electronics.

## Contents
- **hardware/**: Schematics, PCB layouts, CAD files.
- **firmware/**: Microcontroller code for various boards (Arduino, STM32, ESP32, etc.).
- **docs/**: Datasheets, project reports, user manuals.

## Projects
### Project 1: Smart Refrigerator Module
- Intelligent temperature monitoring
- Camera integration for inventory management
- MQTT-based data communication
